# Notes App (React)

## Project Overview
A note-taking app built for the Unlox Week 04 Minor Project to practise components, props, state and hooks.

## Features Implemented
- Create, edit, delete notes
- Responsive card grid
- Search by title/content (bonus)
- Categories with colour-coded cards and filter chips (bonus)
- Timestamps showing last update (bonus)
- Local Storage persistence via useEffect (bonus)

## Technologies Used
React 18 (functional components, hooks), JavaScript (ES6+), Vite, CSS3 (responsive, Grid/Flexbox), Local Storage

## Setup Instructions
```bash
cd notes-app
npm install
npm run dev   # open the URL shown in the terminal
npm run build # production build
```
Requires Node.js 18+.
