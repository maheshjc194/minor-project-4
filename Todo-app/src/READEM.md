# To-Do App (React)

## Project Overview
A task manager built for the Unlox Week 04 Minor Project to practise components, props, state and hooks.

## Features Implemented
- Add, edit, delete tasks
- Mark tasks complete, with a Completed/Pending status badge
- Filter by All / Pending / Completed (bonus)
- Due dates with overdue highlighting (bonus)
- Local Storage persistence via useEffect (bonus)
- Responsive layout

## Technologies Used
React 18 (functional components, hooks), JavaScript (ES6+), Vite, CSS3 (responsive, Grid/Flexbox), Local Storage

## Setup Instructions
```bash
cd todo-app
npm install
npm run dev   # open the URL shown in the terminal
npm run build # production build
```
Requires Node.js 18+.
